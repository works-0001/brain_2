# brain_1

## セットアップ

```bash
git clone <repo>
pnpm install
pnpm dev
```

## コマンド

| コマンド          | 説明                                   |
| ----------------- | -------------------------------------- |
| `pnpm dev`        | 開発サーバー起動（frontend + backend） |
| `pnpm build`      | プロダクションビルド                   |
| `pnpm test`       | ユニットテスト                         |
| `pnpm lint`       | ESLint                                 |
| `pnpm format`     | Prettier チェック                      |
| `pnpm type-check` | TypeScript 型チェック                  |
| `pnpm storybook`  | Storybook 起動                         |
